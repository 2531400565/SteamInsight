# Steam Insight v1.0 产品需求文档（归档）

> 本文档归档 v1.0 的需求与**实际交付状态**。逐条对照，未实现或偏离的都在最后一节列出，不含糊。

---

## 1. 产品定位

**Steam Insight** 是一款 Windows 桌面软件，做 Steam 游戏数据分析与折扣助手。

一句话：**用 Steam 官方数据，在本地建一个比原生 Steam 更细的分析库。**

核心价值：

1. 把 Steam 只给的「累计时长 / 最近两周时长」变成可用的时间维度分析（日 / 周 / 月 / 年 / 时段 / 热力图）。
2. 把成就、愿望单降价、折扣浏览聚到一个本地界面，不依赖 Steam 客户端界面。
3. 年度回顾（Wrapped）可导出成分享海报。

## 4. 功能需求明细

### 4.1 登录与数据获取

- Steam 官方 OpenID 授权：打开系统默认浏览器 → 回调本地 `127.0.0.1` 回环服务 → `check_authentication` 校验 → 取回 SteamID64。
- 读取游戏库 / 成就 / 愿望单需要 **Steam Web API Key**（免费申请），界面给出申请入口说明。
- 提示用户把 Steam 隐私设置的「游戏详情」设为公开，否则游戏库为空。
- 离线导入：不联网，用内置演示数据集填充，全部界面可用。

### 4.2 Steam 智能检测

五项检测：Steam 是否安装、是否运行、客户端是否登录、网络是否可达、以及本机安装路径。

- 实现手段：注册表 `HKCU\Software\Valve\Steam` / `reg query` / `tasklist` / `loginusers.vdf` 解析 / 网络探针，每个探针 3–8s 超时，任一失败不影响其余项。
- **「客户端是否登录」以注册表 `ActiveProcess\ActiveUser` 为唯一权威依据**（非 0 = 当前在线用户，值是 SteamID3）。
  `loginusers.vdf` 只能用来取昵称与账号名——新版 Steam 已不再写 `MostRecent` 字段，只凭它判定会**永远误报「未登录」**。
  `AutoLoginUser` 只是「记住的账号」，不等于在线，仅作兜底。
- **网络探针必须走 Chromium 网络栈**（Electron `net`），才能读到系统代理与系统证书链；
  Node 自带 `https` 既不读系统代理、也不认本地代理的证书链，在开着本地加速器的机器上会**稳定误报「网络不可达」**。
  判定通过还要求响应体确实是 Steam 的数据（`servertime` / `success:true`），只看 HTTP 200 会被本地反代的错误页骗过去。
- 检测到本机已登录账号时，欢迎页给出**快捷登录卡片**（昵称 / 账号名 / SteamID64）并可一键填入；
  检测未就绪时明确指出缺哪一项，不只给一个「不可达」。
- 网络不可达时提示：「建议开启 **Watt Toolkit** 后重试」。**不出现任何 VPN 表述。**

### 4.3 通知

三种触发条件（可在设置里各自开关）：

| 通知 | 触发条件 | 去重 |
| --- | --- | --- |
| 愿望单降价 | 愿望单中任意游戏出现折扣 | 跨重启：`wishlist.notified_at` |
| 今日史低 | 现价 ≤ 本机历史采样最低价 | 跨重启：`discounts.notified_at` |
| 免费游戏提醒 | 折扣列表出现「原价 > 0 且现价 0」的限时免费条目（F2P 不算） | 跨重启：`discounts.notified_at` |

同一类提醒不会重复推送：定时同步每 15 分钟跑一次，若每次都重弹同一批内容，用户会直接关掉通知。
三条都做到了**跨重启**去重（各自的 `notified_at` 列），另用一次运行内的 `类型:appId:价格` 兜住
「已弹出、落库还没跟上」的窗口。促销结束后条目会被清理、`notified_at` 随之消失 ——
该游戏下次再打折是全新一行，因此不会出现「提醒过一次就永久沉默」。

点击通知跳转到对应页面；设置页提供「发送测试通知」。

### 4.5 设置项

- 通用：开机自动启动、最小化到系统托盘、自动同步开关、同步间隔（15 / 30 / 60 分钟）
- 通知：三类通知开关 + 发送测试通知
- 外观：深色 / 浅色 / 跟随系统
- 账号与 API：Web API Key、SteamID64、退出登录
- 数据：八张表行数概览、分表导出、重新同步全部数据、清除缓存（仅清可重建的派生数据）
- 关于：运行环境版本、数据库与配置目录路径、重新检测 Steam

## 5. 能力边界（PRD 明确要求「不假装能做到」）

这三条必须在界面与文档中一致地说明，**不允许用看起来像的数据糊过去**：

1. **每日游玩时长不是 Steam 提供的。** 来自「快照差分采样」（真实数据，但无法追溯安装前的历史）或「内置演示数据集」。
2. **「史低」是本机口径。** 即「当前价 ≤ 本机采样到的最低价」，不等于 Steam 全历史最低价。
3. **首次游玩日期是推算值。** 取最早会话与最早达成成就的较小值，界面用「约」标注。

界面落地位置：Dashboard 底部说明条、Store 页底部口径说明、Game 详情页「约 2026-09-13 依据成就解锁时间推算」、全局「预览模式 · 演示数据」状态徽标。

## 6. 视觉规格

- 配色：Steam 蓝主色（`#66c0f4` 深色主题 / `#1b6dd5` 浅色主题），辅助色 `#2d7dd2`、`#1b6dd5`。
- 风格：Windows 11 Fluent + 毛玻璃面板（`backdrop-filter: blur(20px) saturate(150%)`）。
- 圆角 16px（卡片 `--radius-card`），柔和阴影（`--si-shadow-soft`）。
- 布局：无边框自绘标题栏（可拖拽）+ 左侧固定 212px 导航 + 右侧内容区独立滚动，内容最大宽 1460px。
- 深色优先，浅色主题同步切换全部图表配色。
